# Clase Electrónica Digital I

Material de apoyo del curso **Electrónica Digital I** de la **Universidad de Ibagué**: guías de proyecto, diapositivas, plantillas de código VHDL y testbenches para practicar en clase.

> Monitores: Brahiam Campiño · Luisa Gallo

## Semestres

| Semestre | Proyecto | Estado |
|---|---|---|
| [**2026-B**](2026-B/) | Sistema digital de monitoreo y control de nivel de un tanque mediante FPGA (DE0-Nano) | En curso |


## Cómo descargar el material

**Opción 1 · Sin Git:** botón verde **Code › Download ZIP** en esta página. Descompriman el archivo y entren a la carpeta de su semestre.

**Opción 2 · Con Git:**
```
git clone https://github.com/Brahiam18/Clase-Electronica-Digital-1.git
```
Para recibir el material nuevo que se vaya publicando: `git pull`.

> Guarden el material en una ruta **sin espacios ni tildes** (por ejemplo `C:/Users/Usuario/Desktop/dig1`). ModelSim y Quartus tienen problemas con esos caracteres.

## Herramientas del curso

- **Quartus Prime Lite** (16.1 o superior), con soporte para Cyclone IV E.
- **ModelSim – Intel FPGA Starter Edition** o **Questa – Intel/Altera FPGA Starter Edition**, incluido con Quartus.
- Tarjeta **DE0-Nano** (Cyclone IV E · EP4CE22F17C6).

Las instrucciones de uso de cada entrega están en el `README` de su carpeta.
